# Demokratisäkrat

Demokratin är gjord för att lösa svåra, långsiktiga frågor — klimat, välfärd, trygghet. Men vår uppmärksamhet, nyhetsflödet och den politiska debatten är gjorda för motsatsen: snabba svar, starka känslor, nästa val. Den krocken gör det svårare att tänka klart om det som faktiskt spelar roll om tio eller tjugo år. Och när debatten pressar varje fråga mot svart eller vitt försvinner platsen där de flesta verkliga avvägningarna faktiskt ligger — i ett ärligt "både och".

Demokratisäkrat bygger öppna verktyg som ska göra det lättare att tänka igenom sådana frågor i lugn och ro.

## Verktyg

- **[Valsnack](https://valsnack.se)** — en valkompass som inte bara frågar vad du tycker: den visar vad dina svar kostar, och vem som får betala. ([källkod](https://github.com/demokratisakrat/konsekvenskompassen))
